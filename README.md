# 좀비 탈출 서버 리소스팩

마인크래프트 26.3 미니게임 서버 "좀비 탈출"에서 쓰는 리소스팩입니다. 서버에 접속하면 자동으로 받으므로 따로 받을 필요는 없습니다.
팩은 두 개입니다. 릴리스 태그 `pack-<그 팩 sha1 앞 12자리>` 마다 파일 하나가 있습니다.

| 파일 | 담긴 것 |
|---|---|
| `ZombieRun-pack.zip` | 모델, 텍스처, HUD, 셰이더, 음악, 소리 사건 정의 |
| `ZombieRun-pack-2.zip` | Left 4 Dead 2 효과음, 생존자 목소리 소리 파일 |

팩 맨 위의 `CREDITS.txt`, `CREDITS-MUSIC.txt`, `LICENSE-*.txt` 에 출처와 라이선스 전문이 들어 있습니다.

비상업 개인 서버입니다. 공식 게임, 공식 모드와 관계가 없습니다.

## Left 4 Dead 2 음악, 효과음, 목소리

음악 일부와 둘째 팩의 효과음, 생존자 목소리는 Valve Corporation 의 Left 4 Dead 2 에서 가져온 것이고 저작권은 Valve 에 있습니다. 서버 운영자가 허락을 받았다고 밝혀 넣었습니다. 이 팩을 다른 곳에 다시 올리지 마세요. 원작의 모델, 맵, 캐릭터 생김새는 쓰지 않았습니다.

아래 표의 좀비 스킨과 일부 효과음은 원작자의 재배포 허락을 확인하지 못했습니다.
